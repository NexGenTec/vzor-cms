
# vzor-cms  
Sistema web de administración y gestión de datos desarrollado con Angular standalone.  
## Instalar dependencias

Instalar mi proyecto con npm 
- Node.js >= 16  
- Angular CLI

```bash
    npm install -g @angular/cli
```
## Ejecutar Localmente

Ir al directorio del proyecto

```bash
  cd vzor-cms
```

Iniciar el servidor

```bash
  ng serve
```
